# template_interfaces

This package serves as a template for creating new interface packages in the `dexe_interfaces` repository. It provides a basic structure and example files that can be copied and modified to create new interfaces.

## Actions (.action)

- [Simple.action](action/Simple.action): An example action file that can be used as a starting point for creating new actions.

## Messages (.msg)

- [Image.msg](msg/Image.msg): An example message file that can be used as a starting point for creating new messages.

## Services (.srv)

- [Echo.srv](srv/Echo.srv): An example service file that can be used as a starting point for creating new services.
