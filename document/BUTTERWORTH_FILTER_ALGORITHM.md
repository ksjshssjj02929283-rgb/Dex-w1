# Butterworth滤波器算法设计文档

## 1 概述

Butterworth滤波器是一种具有平坦幅度响应的IIR（无限冲击响应）数字滤波器。本实现采用二阶巴特沃斯低通滤波器，截止频率3Hz，用于平滑关节速度反馈信号，消除高频噪声。

## 2 核心算法

### 2.1 差分方程

二阶IIR滤波器差分方程：

$$
y[n] = \sum_{i=0}^{2} b_i \cdot x[n-i] - \sum_{i=1}^{2} a_i \cdot y[n-i]
$$

其中：
- $x[n]$ 为输入信号
- $y[n]$ 为输出信号
- $b_i$ 为前向系数（分子）
- $a_i$ 为反馈系数（分母，$a_0=1$）

### 2.2 滤波器系数

本实现预计算系数（采样频率1000Hz，截止频率3Hz）：

| 系数 | 值 |
|------|------|
| $b_0$ | 8.765554875401464e-05 |
| $b_1$ | 0.00017531109750802928 |
| $b_2$ | 8.765554875401464e-05 |
| $a_1$ | -1.9733442497812987 |
| $a_2$ | 0.9736948719763148 |

系数满足 $b_0 = b_2$（对称特性），确保滤波器线性相位特性。

### 2.3 初始化策略

首次调用时，将历史缓冲区填充为输入值，避免启动瞬态：

$$
x[0]=x[1]=x[2]=input, \quad y[0]=y[1]=y[2]=input
$$

### 2.4 实时实现

使用滑动窗口缓冲区存储最近2个输入/输出样本。每次采样：

1. 移动历史缓冲区（深度为2）
2. 追加新输入
3. 按差分方程计算输出

## 3 功能模块

### 3.1 构造函数

预加载固定系数，适用于3Hz截止频率的二阶低通滤波。

### 3.2 Apply

执行单次滤波，返回平滑后的值。

### 3.3 Reset

重置历史缓冲区和初始化标志，为新数据流做准备。

## 4 频率响应

- 通带纹波：0dB（最大平坦）
- 截止频率：3Hz（-3dB点）
- 采样频率：1000Hz
- 阻带衰减：约-12dB/oct（二阶特性）

## 5 应用场景

- 关节速度反馈信号平滑
- 传感器噪声抑制
- 控制指令滤波（与输入整形配合使用）
