# AF-ARF 无加速度动力学参数辨识

本文说明 AF-ARF（Acceleration-Free Analytical Regressor Filtering）的算法组成，以及它在 [`qt_dyn_params_ident.py`](../script/qt_dyn_params_ident.py) 中的实现。整体采集、物理约束和配置写入流程见 [动力学参数辨识](dynamics_parameter_identification.md)。

## 1. 目标与输入输出

传统辨识需要根据 `q`、`dq`、`ddq` 构造动力学回归矩阵。位置连续差分两次得到 `ddq`，容易放大测量噪声。

AF-ARF 对动力学方程进行低通滤波，通过分部积分消去加速度，直接用 `q`、`dq` 和测量力矩构造回归方程：

```text
传统回归：τ    = H(q, dq, ddq) · θ
AF-ARF： τ_f  = H_f(q, dq, 历史数据) · θ
```

`θ` 是完整动力学参数向量。滤波改变回归矩阵和测量力矩，不改变待辨识参数的物理含义。无加速度并不等于令 `ddq = 0`；惯性项仍参与辨识。

Qt 当前采用 AF-ARF 构造回归数据，再执行离线约束最小二乘。论文中的在线复合学习和自适应控制律未接入 Qt。

## 2. 算法组成

### 2.1 将动力学改写为动量形式

机器人动力学为：

```text
τ = M(q) · ddq + C(q, dq) · dq + g(q) + f(dq)
```

定义关节动量 `p = M(q) · dq`。根据论文推导过程，利用刚体动力学恒等式 `dotM = C + Cᵀ`，得到：

```text
dotp = M · ddq + dotM · dq
τ    = dotp - Cᵀ · dq + g + f
```

这样，加速度集中在动量导数 `dotp` 中，其余项只需要位置和速度。

### 2.2 第一层滤波消去动量导数

定义零初始状态的一阶低通算子：

```text
Fα(s) = α / (s + α)
```

对方程两边使用相同滤波，并对 `dotp` 分部积分：

```text
Fα[dotp] = αp - αexp(-α(t-t0))p(t0) - Fα[αp]

τ_f = αp - Fα[αp - g + Cᵀ·dq]
      - αexp(-α(t-t0))p(t0) + Fα[f]
```

右侧不再需要 `ddq` 或 `dotp`。初始动量项用于处理采集起点速度不为零的情况；起点静止时该项为零。

### 2.3 用原始回归函数构造三个动力学项

不需要单独推导每个连杆的积分表达式。AF-ARF 通过多次调用原有回归函数，构造动量、重力和科氏转置项的回归矩阵。

设 `H₀` 为原始回归矩阵中将摩擦列置零后的矩阵，保持原参数列顺序：

| 矩阵 | 构造方法 | 对应力矩或动量 |
|---|---|---|
| `G` | `H₀(q, 0, 0)` | `G·θ = g(q)` |
| `P` | `H₀(q, 0, dq) - G` | `P·θ = M(q)·dq` |
| `T` | 对速度二次项做极化，再与 `dq` 收缩 | `T·θ = Cᵀ(q,dq)·dq` |

其中 `H₀(q, 0, dq)` 的第三个参数是代数上的辅助输入，用来提取 `M·dq`，不是测量加速度，也不是将速度当作实际加速度。

构造 `T` 时，对第 `j` 个单位向量 `e_j` 计算：

```text
B_j = 0.5 · [H₀(q, dq+e_j, 0) - H₀(q, dq, 0)
             - H₀(q, e_j, 0) + G]
T[j, :] = dqᵀ · B_j
```

`B_j·θ` 对应 `C` 的第 `j` 列，因此 `dqᵀ·B_j` 得到 `Cᵀ·dq` 的第 `j` 个分量。这一步依赖刚体动力学速度项的二次结构；摩擦列必须先排除。

### 2.4 单独加入摩擦回归

Qt 使用库仑、黏性和偏置摩擦模型：

```text
f_i = fv_i · dq_i + fc_i · tanh(dq_i / v_s) + fo_i
```

其中当前 `v_s = 0.1 rad/s`，用于将库仑摩擦在零速附近平滑化。

摩擦项本身不含加速度。令 `H_F` 只保留原矩阵的摩擦列，其余列置零，直接低通后合并：

```text
H_f = αP - Fα[αP - G + T]
      - αexp(-α(t-t0))P(t0) + Fα[H_F]
τ_f = Fα[τ]

τ_f = H_f · θ
```

惯性、重力与摩擦列保留原有顺序，简化驱动惯量也保留在动量项中。当前摩擦系数为各关节常数，没有加入论文讨论的位置相关耦合摩擦模型。

## 3. 为什么有两层滤波

第一层公式中存在直接使用速度的 `αP`，该项没有经过低通，速度噪声仍可能进入回归矩阵。论文因此在第一层结果上增加第二层低通：

```text
Fβ(s) = β / (s + β)
H_ff  = Fβ[H_f]
τ_ff  = Fβ[τ_f]

τ_ff = H_ff · θ
```

| Qt 参数 | 作用 | 默认值 | 对应单级截止频率 |
|---|---|---|---|
| `alpha` | 构造无加速度回归，是当前算法必要的一层 | `15 s^-1` | `alpha/(2π) ≈ 2.39 Hz` |
| `beta` | 进一步抑制第一层结果中的噪声，可关闭 | `10 s^-1` | `beta/(2π) ≈ 1.59 Hz` |

两层都作用于回归矩阵和测量力矩，保证方程两边一致。`beta = 0` 在代码中表示跳过第二层，不是使用零增益滤波器。`alpha` 必须大于零。

参数越小，平滑越强、延迟越大，也越容易削弱激励信息。两层串联后的整体截止频率不能直接取任意一个单级截止频率；不能只根据曲线更平滑或滤波残差更小判断模型更准确。

Qt 还会在计算速度前对位置做 Butterworth 零相位滤波，这是差分前的数据预处理，与上述两层回归滤波分工不同。关闭 `beta` 不会关闭位置滤波或 `alpha`。

## 4. Qt 中的数据处理流程

选择“AF-ARF（无需 ddq）”后，`process_acceleration_free_data()` 执行：

1. 按反馈时间戳将位置、电流估算力矩和传感器力矩共同重采样到 `dt` 网格；重复时间戳保留最后一条记录。
2. 对位置做三阶 Butterworth 零相位滤波，再做一次中心差分得到 `dq`，不计算 `ddq`。
3. 识别完整参数中的摩擦列，通过 `G`、`P`、`T` 和摩擦列构造第一层回归矩阵。
4. 对电流估算力矩应用同样的 `alpha` 滤波；若 `beta > 0`，再同时滤波矩阵和力矩。
5. 完整记录滤波后，裁掉开始约 3 秒和结束约 1 秒的数据。
6. 将各时刻、各关节的矩阵纵向堆叠，选择最小参数列，执行 QR 分解。

低通由 [`acceleration_free_regressor.py`](../script/dyn_params_ident/acceleration_free_regressor.py) 实现。每个采样间隔采用输入线性插值下的指数积分更新，滤波状态从零开始。实际辨识仍受采样与预处理误差影响。

辨识仍使用电流估算力矩 `joint_torque`。`joint_torque_sensor` 经过相同的 `alpha`、`beta` 滤波后只用于对比。

位置滤波沿用现有截止频率约定：传入 SciPy 的归一化频率为 `fc·2π·dt`，对应单向滤波器设计截止频率约为 `π·fc`，不能把 `get_filter_cutoff()` 返回值直接理解为实际截止频率；双向滤波还会改变整体幅频响应。

## 5. 求解、验证与参数使用

两种算法共用 SymPyBotics 模型、最小参数顺序和物理约束求解器。AF-ARF 最终求解：

```text
minimize    ‖W_ff · β_base - ω_ff‖²
subject to  惯性矩阵约束、驱动惯量和摩擦正值约束
            质心包围盒约束、整臂质量上限
```

这里 `β_base` 是动力学最小参数集，与界面中的第二层滤波速率 `beta` 是不同概念。

`traj1` 用于求解，`traj2` 用于独立验证。AF-ARF 验证图中的预测值为**滤波后的力矩**，应与同样滤波的电流估算力矩或传感器力矩比较。缺少 `traj2` 时仍可求解，但没有独立轨迹验证结果。

验证通过后，参数仍写入 `dyn_base_params_primary` 和 `dyn_base_params_secondary`。只要模型、参数顺序和坐标系一致，运行时可直接使用原符号逆动力学函数，无需对力矩再应用 AF-ARF 滤波。

在线控制是否使用 `ddq = 0` 是另一项控制策略选择。AF-ARF 消去的是辨识对加速度测量的需求，并没有删除模型的惯性参数，也不保证拖动示教一定更顺滑。
